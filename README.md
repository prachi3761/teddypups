# 🧸 TeddyPups U.A.E. — Premium Puppy Website Clone

A playful, hand-drawn style website inspired by a Dubai-based miniature puppy brand. Built using pure HTML, CSS and JavaScript, featuring adorable animations, interactive pages and a responsive design.

## 🎬 Animated Website Preview

![TeddyPups Website Animation](assets/teddypups-demo.gif)

*Watch the animated website preview, including page transitions, puppy animations and interactive elements.*

## ✨ Features

- **6 Interactive Pages:** Home, Puppies, Happy Families, How It Works, FAQ, Visit & Contact.
- **Poodle Loading Animation:** A cute poodle runs across a lattice-pattern screen during page transitions.
- **Smooth Page Transitions:** Animated navigation between different sections.
- **Puppy Filters:** Filter puppies by location, breed and gender.
- **Happy Families:** Polaroid-style gallery and customer testimonials.
- **FAQ Search:** Searchable corkboard-style FAQ section.
- **How It Works:** Toggle between In Dubai and Imported journeys.
- **WhatsApp Contact Form:** Opens WhatsApp with a pre-filled message.
- **Responsive Design:** Optimized for mobile, tablet and desktop.
- **Dark Mode:** Supports device light and dark preferences.
- **Accessibility:** Keyboard focus indicators and reduced-motion support.

## ⚠️ Limitations

- No backend or database.
- Puppy information is hard-coded.
- Contact form opens WhatsApp instead of storing submissions.
- Puppy visuals are currently represented by placeholder emoji and illustrations.
- No individual puppy profile pages.
